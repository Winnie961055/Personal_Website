# Hsing-Yu Wen — Personal Website

A responsive, static portfolio site built with semantic HTML, modern CSS, and lightweight JavaScript.

## Preview locally

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deploy

The site has no build step. Deploy the repository root directly to GitHub Pages, Netlify, or Vercel.

## Content

- `index.html` — page structure and portfolio content
- `styles.css` — visual system and responsive layouts
- `script.js` — mobile navigation, active section state, and scroll reveals
